# Conselhos Profissionais

**PRJ-000007 — Projeto público, independente e não oficial**

Pesquisar, sistematizar e acompanhar os conselhos de fiscalização profissional brasileiros, sua organização institucional, suas competências e sua atuação regulatória.

Este repositório é a base pública versionada para organizar a pesquisa e desenvolver materiais documentais sobre conselhos e entidades brasileiras de fiscalização profissional, observadas as particularidades de cada regime e instituição.

## Estado do Projeto

A missão e a estrutura documental inicial foram constituídas com o **Gerador de Agents (PRJ-000002)**, preservando os registros anteriores. **Ainda não foi publicado ou certificado um corpus de pesquisa substantivo ou site independente.** O repositório GitHub é público; isso não equivale à ativação de GitHub Pages.

## Escopo e método

- Mapa institucional e classificação dos conselhos com critérios explícitos.
- Fundamentos normativos, organização federal/regional quando existente e competências.
- Poderes regulamentares, fiscalização, disciplina, deveres de transparência e limites, conforme fontes.
- Atualizações normativas e decisões relevantes, com data, órgão e contexto.

Os estudos posteriores deverão citar fontes oficiais verificadas, informar recorte e data e distinguir normas, fatos, interpretação e questões abertas. Não há afiliação, representação ou endosso de qualquer órgão ou entidade analisada.
